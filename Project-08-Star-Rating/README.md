# Project 08 — Star Rating Component

**Difficulty:** Intermediate  
**Technology:** HTML / CSS / JavaScript  
**Time target:** 20 minutes

## Problem Statement

Complete rate(selectedIndex) so all stars up to and including the clicked star have the active class.

## Requirements

- Complete rate(selectedIndex) so all stars up to and including the clicked star have the active class.
- Remove active from every later star, including when the user lowers the rating.
- Update #ratingValue to the selected rating from 1 to 5.

## Constraints

Do not modify the HTML to complete the exercise. Use the active CSS class to control selection.

## Expected Behaviour / Manual Checks

- [ ] Initially all stars are inactive and Rating: 0.
- [ ] Click the third star: first three are gold and Rating: 3.
- [ ] Then click the first: only the first is gold and Rating: 1.
- [ ] Click the fifth: all five are gold and Rating: 5.

## Files to Modify

Complete TODOs in script.js. Keep the supplied HTML ids, function names, event wiring, and CSS.

## Run

Open index.html directly in a modern browser. No installation or server is required. Alternatively, use the VS Code Live Server extension.

## Starter Status

The page loads with its initial UI. Its exercise handlers are intentionally unfinished, so clicks or typing will not yet produce the required updates. No exercise solutions are included. A successful page load or build verifies the scaffold, not completion of the exercise.
