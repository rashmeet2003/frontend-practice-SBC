# Project 07 — Theme Color Selector

**Difficulty:** Intermediate  
**Technology:** HTML / CSS / JavaScript  
**Time target:** 15 minutes

## Problem Statement

Complete changeColor(button) using the clicked button’s data-color attribute.

## Requirements

- Complete changeColor(button) using the clicked button’s data-color attribute.
- Apply that color to the background of #preview.
- The same function must work for every color button.

## Constraints

Do not modify the HTML to complete the exercise. Read data-color dynamically; do not create separate red/blue/green branches.

## Expected Behaviour / Manual Checks

- [ ] Red, Blue, and Green each produce the corresponding preview background.
- [ ] Selecting another color replaces the previous color.
- [ ] Changing a button’s data-color for a manual check works without changing the handler.

## Files to Modify

Complete TODOs in script.js. Keep the supplied HTML ids, function names, event wiring, and CSS.

## Run

Open index.html directly in a modern browser. No installation or server is required. Alternatively, use the VS Code Live Server extension.

## Starter Status

The page loads with its initial UI. Its exercise handlers are intentionally unfinished, so clicks or typing will not yet produce the required updates. No exercise solutions are included. A successful page load or build verifies the scaffold, not completion of the exercise.
