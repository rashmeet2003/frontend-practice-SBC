# Project 06 — Tab Switcher

**Difficulty:** Intermediate  
**Technology:** HTML / CSS / JavaScript  
**Time target:** 15–20 minutes

## Problem Statement

Complete showTab(id) to display only the requested panel.

## Requirements

- Complete showTab(id) to display only the requested panel.
- Select all panels through the shared panel class and hide them before showing the requested panel.
- Profile is visible initially; switching repeatedly must still leave exactly one panel visible.

## Constraints

Do not modify the HTML to complete the exercise. Use the common panel class; do not hardcode a separate hide operation for each panel.

## Expected Behaviour / Manual Checks

- [ ] Initially only Student Profile is visible.
- [ ] Skills shows HTML, CSS, JavaScript and hides the other panels.
- [ ] Projects then Profile each show only their own panel.

## Files to Modify

Complete TODOs in script.js. Keep the supplied HTML ids, function names, event wiring, and CSS.

## Run

Open index.html directly in a modern browser. No installation or server is required. Alternatively, use the VS Code Live Server extension.

## Starter Status

The page loads with its initial UI. Its exercise handlers are intentionally unfinished, so clicks or typing will not yet produce the required updates. No exercise solutions are included. A successful page load or build verifies the scaffold, not completion of the exercise.
