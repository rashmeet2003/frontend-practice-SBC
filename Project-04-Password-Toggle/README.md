# Project 04 — Password Show/Hide

**Difficulty:** Intermediate  
**Technology:** HTML / CSS / JavaScript  
**Time target:** 10–12 minutes

## Problem Statement

Complete togglePassword() to alternate the input type between password and text.

## Requirements

- Complete togglePassword() to alternate the input type between password and text.
- Keep the button label in sync: Show Password when hidden, Hide Password when visible.
- Preserve the entered password while toggling.

## Constraints

Do not modify the HTML to complete the exercise.

## Expected Behaviour / Manual Checks

- [ ] Initially the sample password is masked and the button says Show Password.
- [ ] First click reveals it and says Hide Password.
- [ ] Second click masks it again and says Show Password.

## Files to Modify

Complete TODOs in script.js. Keep the supplied HTML ids, function names, event wiring, and CSS.

## Run

Open index.html directly in a modern browser. No installation or server is required. Alternatively, use the VS Code Live Server extension.

## Starter Status

The page loads with its initial UI. Its exercise handlers are intentionally unfinished, so clicks or typing will not yet produce the required updates. No exercise solutions are included. A successful page load or build verifies the scaffold, not completion of the exercise.
